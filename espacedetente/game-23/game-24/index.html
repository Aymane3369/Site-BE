Tome 1

🌲 Introduction aux structures bois

Histoire, domaines d'application, avantages et limites du bois. Comportement mécanique, anisotropie, hygroscopicité, durabilité naturelle.
Concepts fondamentaux
Anisotropie : Le bois a des propriétés différentes selon les directions (longitudinale, radiale, tangentielle).
Hygroscopicité : Le bois absorbe et libère de l'eau avec les variations d'humidité.
Durabilité naturelle : Variable selon les essences (durable : chêne, robinier ; non durable : épicéa, pin).
Points clés : Le bois est un matériau renouvelable, léger, avec un excellent rapport résistance/poids.
Domaine : Toutes les structures bois Anisotropie : 3 directions Hygroscopicité : humidité d'équilibre
Exemple : Une poutre en bois lamellé-collé de 12 m de portée peut supporter des charges importantes avec une section réduite (ex: 200×600 mm) grâce au rapport résistance/poids élevé du bois.
Exercice 1.1 : Calculer la masse d'une poutre en bois lamellé-collé GL28 de section 200×600 mm et de longueur 12 m. Masse volumique ρ = 450 kg/m³.
Corrigé :
Volume = 0,2 × 0,6 × 12 = 1,44 m³
Masse = 1,44 × 450 = 648 kg
Comparaison avec du béton (2500 kg/m³) : masse béton équivalente = 1,44 × 2500 = 3 600 kg → le bois est 5,5 fois plus léger.

Influence sur les coefficients

Tome 5

⚖️ Actions sur les structures

Selon les Eurocodes EN 1990 et EN 1991 : charges permanentes G, charges d'exploitation Q, neige, vent, séisme, température.
Actions courantes sur les structures bois
G : poids propre de la structure (bois, couverture, isolation)
Q : charges d'exploitation (entretien, stockage)
S : charges de neige (EN 1991-1-3)
W : charges de vent (EN 1991-1-4)
E : charges sismiques (EN 1998)
T : actions thermiques
Exemple : Pour une charpente de maison individuelle (zone 1), charges typiques :
Gk = 0,5 kN/m² (couverture + isolation), Qk = 0,5 kN/m² (entretien), Sk = 0,45 kN/m² (neige), Wk = 0,6 kN/m² (vent).

Combinaisons ELU (EN 1990)

Tome 7

📐 Coefficients de calcul

γM, kmod, kdef, kh, ksys, km.
Coefficients principaux (Eurocode 5)
γM = 1,3 (bois massif, lamellé-collé)  ·  = 1,2 (panneaux)
kmod = coefficient de modification (0,5 à 0,9 selon la classe de service et la durée de charge)
kdef = coefficient de fluage (0,6 à 2,0 selon la classe de service)
kh = coefficient de hauteur (pour les poutres en bois massif)
ksys = coefficient de système (pour les éléments répartis)
km = coefficient de redistribution des contraintes (flexion déviée)
Exemple : Pour une poutre en GL28, classe de service 2, charge de courte durée :
kmod = 0,80, γM = 1,25
fm,d = 0,80 × 28 / 1,25 = 17,92 MPa

Tome 10

⚡ Vérifications ELU

Flexion simple, flexion déviée, traction, compression, cisaillement, flambement, déversement, instabilité latérale.
Formules ELU (Eurocode 5)
Flexion simple : σm,d = MEd / W ≤ fm,d
Flexion déviée : (σm,y,d / fm,y,d) + (σm,z,d / fm,z,d) ≤ 1
Traction : σt,0,d = NEd / A ≤ ft,0,d
Compression : σc,0,d = NEd / A ≤ fc,0,d
Cisaillement : τd = (1,5·VEd) / A ≤ fv,d
Flambement : σc,0,d ≤ kc·fc,0,d (kc = facteur de flambement)
Déversement : σm,d ≤ kcrit·fm,d (kcrit = facteur de déversement)
Exemple : Poutre GL24, section 200×400 mm, MEd = 50 kN·m
W = 200×400²/6 = 5,33×10⁶ mm³
σm,d = 50×10⁶ / 5,33×10⁶ = 9,38 MPa
fm,d = 0,8×24/1,25 = 15,36 MPa → 9,38 ≤ 15,36 → ✅ OK
Exercice 10.1 : Vérifier en flexion une poutre GL28 de section 180×360 mm soumise à MEd = 45 kN·m. Classe de service 2, courte durée, γM = 1,25.
Corrigé :
W = 180×360²/6 = 3,89×10⁶ mm³
σm,d = 45×10⁶ / 3,89×10⁶ = 11,57 MPa
fm,d = kmod·fm,k/γM = 0,8×28/1,25 = 17,92 MPa
11,57 ≤ 17,92 → ✅ OK
Tome 11

📏 Vérifications ELS

Flèche instantanée, flèche finale, vibrations, fluage, ouverture des assemblages.
Formules ELS (Eurocode 5)
Flèche instantanée : uinst = (5·p·L⁴) / (384·E·I)
Flèche finale : ufin = uinst · (1 + kdef)
Flèche nette : unet = ufin − ure (contre-flèche)
Limites : uinst ≤ L/300, ufin ≤ L/200, unet ≤ L/250
Vibrations : f ≥ 8 Hz (planchers) et flèche sous charge de 1 kN ≤ 2 mm
Exemple : Poutre GL24, section 200×400 mm, L = 6 m, pELS = 5 kN/m
I = 200×400³/12 = 1,07×10⁹ mm⁴
uinst = 5×5×6000⁴ / (384×11600×1,07×10⁹) = 6,8 mm
kdef = 0,8 (classe 2) → ufin = 6,8×1,8 = 12,2 mm
L/300 = 20 mm, L/200 = 30 mm → ✅ OK
Exercice 11.1 : Vérifier la flèche d'une solive en C24 de section 75×200 mm, portée 4 m, pELS = 2 kN/m. E0,mean = 11 000 MPa, kdef = 0,6.
Corrigé :
I = 75×200³/12 = 50×10⁶ mm⁴
uinst = 5×2×4000⁴ / (384×11000×50×10⁶) = 4,8 mm
ufin = 4,8 × (1+0,6) = 7,7 mm
L/300 = 13,3 mm → ✅ OK
Tome 12

🔩 Assemblages

Pointes, vis, boulons, broches, goujons, tiges filetées, platines, connecteurs. Cisaillement, arrachement, écrasement, effet de levier, modes de rupture (Johansen).
Théorie de Johansen (Eurocode 5)
Résistance au cisaillement : Fv,Rd = min(F1, F2, F3, ...) selon les modes de rupture
Mode 1 : F1 = fh · t1 · d
Mode 2 : F2 = fh · t2 · d
Mode 3 : F3 = (fh · t1 · d) / (2 + (4·My,Rd) / (fh · d · t1²))
Effet de levier : My,Rd = 0,8 · fy,k · W
Arrachement : Fax,Rd = fax,k · d · t · kmod / γM
Exemple : Assemblage boulonné (d = 12 mm) dans du GL24, épaisseur t = 40 mm, fh = 18 MPa
Fv,Rd = 18 × 40 × 12 = 8 640 N (mode 1, sans effet de levier)
Exercice 12.1 : Calculer la résistance d'un assemblage boulonné (d=16 mm) dans du GL28, épaisseur 50 mm, fh = 20 MPa. Vérifier le mode 1.
Corrigé :
Fv,Rd = fh × t × d = 20 × 50 × 16 = 16 000 N = 16 kN
Vérification de l'effet de levier (négligé pour ce cas).
Tome 13

🏠 Charpentes

Toitures traditionnelles : chevrons, pannes, arbalétriers, entraits, poinçons, contrefiches. Calcul complet sous charges de couverture, neige et vent.
Calcul des chevrons (Eurocode 5)
Charge totale : p = (G + Q) · espacement + S · espacement
Moment : MEd = p · L² / 8
Vérification : σm,d = MEd / W ≤ fm,d
Flèche : u = 5·p·L⁴ / (384·E·I) ≤ L/300
Pannes : vérifier en flexion et cisaillement sous neige
Arbalétriers : compression + flexion (élément incliné)
Exemple : Chevron en C24, section 63×175 mm, espacement 50 cm, portée 3 m, charges G=1,2 kN/m², Q=0,5 kN/m², S=0,45 kN/m²
p = (1,2+0,5+0,45)×0,5 = 1,08 kN/m
MEd = 1,08×3²/8 = 1,22 kN·m → OK
Tome 14

🧱 Ossature bois

Montants, traverses, lisses, voiles travaillants, contreventement. Calcul des montants en compression + flexion composée.
Calcul des montants d'ossature
Compression : σc,0,d = NEd / A ≤ fc,0,d
Flambement : σc,0,d ≤ kc · fc,0,d
Flexion composée : (σc,0,d / fc,0,d) + (σm,d / fm,d) ≤ 1
Voiles travaillants : vérification du contreventement sous vent
Exemple : Montant C24 75×150 mm, NEd = 15 kN, MEd = 2 kN·m
A = 75×150 = 11 250 mm², W = 75×150²/6 = 281 250 mm³
σc,0,d = 15×10³/11250 = 1,33 MPa
σm,d = 2×10⁶/281250 = 7,11 MPa
Vérification : 1,33/10 + 7,11/12 = 0,13 + 0,59 = 0,72 ≤ 1 → OK
Tome 15

🪵 CLT (Cross Laminated Timber)

Calcul des panneaux en flexion, cisaillement, déformations, assemblages. Panneaux à 3, 5 ou 7 couches.
Calcul des panneaux CLT
Flexion : σm,d = MEd / Weff ≤ fm,d
Cisaillement : τd = VEd · S / (Ieff · b) ≤ fv,d
Flèche : u = (5·p·L⁴) / (384·Eeff·Ieff)
Rigidité effective : Eeff·Ieff = Σ (Ei·Ii) + Σ (Ei·Ai·ai²)
Exemple : Panneau CLT 5 couches (20+20+20+20+20 = 100 mm), portée 4 m, p = 5 kN/m²
Eeff·Ieff ≈ 1,2×10¹² N·mm²
u = 5×5×4000⁴ / (384×1,2×10¹²) = 5,8 mm ≤ L/300 = 13,3 mm → OK
Tome 16

📐 Stabilité

Flambement des poteaux, déversement des poutres, instabilités globales, vérifications des portiques.
Formules de stabilité (Eurocode 5)
Flambement (poteaux) : σc,0,d ≤ kc · fc,0,d
kc : facteur de flambement (1 / (k + √(k² − λrel²)))
λrel : élancement relatif = (λ / π) · √(fc,0,k / E0,05)
Déversement : σm,d ≤ kcrit · fm,d
kcrit : facteur de déversement (1,0 si λrel,m ≤ 0,75)
Exemple : Poteau GL24 200×200 mm, L = 4 m, NEd = 200 kN
i = 0,289×200 = 57,8 mm, λ = 4000/57,8 = 69
λrel = (69/π) × √(24/7400) = 1,0
kc ≈ 0,60
σc,0,d = 200×10³ / 40000 = 5,0 MPa
fc,0,d = 0,8×24/1,25 = 15,36 MPa
5,0 ≤ 0,60×15,36 = 9,22 MPa → OK
Tome 17

🔥 Résistance au feu

Selon l'Eurocode 5 : vitesse de carbonisation, section résiduelle, vérification R30, R60, R90 et R120.
Formules de résistance au feu
Vitesse de carbonisation : β = 0,65 mm/min (bois massif), β = 0,45 mm/min (lamellé-collé)
Section résiduelle : dchar = β · tfeu
Section effective : beff = b − 2·dchar  ·  heff = h − dchar
Vérification : MEd,feu ≤ MRd,feu
Classes : R30 (30 min), R60 (60 min), R90 (90 min), R120 (120 min)
Exemple : Poutre GL28 200×600 mm, R60 (60 min)
dchar = 0,45 × 60 = 27 mm
beff = 200 − 2×27 = 146 mm
heff = 600 − 27 = 573 mm
Section résiduelle = 146×573 mm (87% de la section initiale)
Exercice 17.1 : Calculer la section résiduelle d'une poutre en bois massif C24 de section 100×200 mm pour une résistance R30 (30 min). β = 0,65 mm/min.
Corrigé :
dchar = 0,65 × 30 = 19,5 mm
beff = 100 − 2×19,5 = 61 mm
heff = 200 − 19,5 = 180,5 mm
Section résiduelle = 61 × 180,5 mm (55% de la section initiale)

📋 Dimensionnement complet

Méthodologie complète pour chaque élément : descente de charges, combinaisons ELU/ELS, calcul des sollicitations, vérifications, assemblages, détails d'exécution.
Méthodologie complète
1. Descente de charges : Gk + Qk + Sk + Wk
2. Combinaisons : ELU et ELS selon EN 1990
3. Sollicitations : MEd, VEd, NEd
4. ELU : flexion, cisaillement, compression, flambement, déversement
5. ELS : flèche instantanée, flèche finale, vibrations
6. Assemblages : boulons, pointes, connecteurs
7. Détails : ancrages, résistance au feu, durabilité
Exemple complet : Poutre en lamellé-collé de 12 m
Données : GL28, section 200×600 mm, portée 12 m, charges G=5 kN/m, Q=3 kN/m, S=2 kN/m (neige)
ELU : MEd = 1,35×5 + 1,5×3 + 1,5×0,5×2 = 13,05 kN/m
MEd = 13,05×12²/8 = 234,9 kN·m
W = 200×600²/6 = 12×10⁶ mm³ → σ = 234,9×10⁶/12×10⁶ = 19,58 MPa
fm,d = 0,8×28/1,25 = 17,92 MPa → ⚠ Non conforme → section insuffisante
Solution : utiliser GL32 ou augmenter la section (ex: 240×650 mm)
