📐 1. Poutres en béton armé
Vérifications complètes pour une poutre soumise à la flexion, au cisaillement, à la torsion et aux ancrages. 📌 Exemple : Poutre de 6 m supportant une dalle d'habitation — Section 30×60 cm
ELU Flexion
Vérification de la résistance en flexion simple
MEd ≤ MRd · As = MEd / (z · fyd)
Exemple : MEd = 120 kN·m → As = 120×10⁶ / (0,9×540×434,8) = 567 mm² → 3 HA16
ELU Effort tranchant
Vérification du cisaillement et dimensionnement des étriers
VEd ≤ VRd,c · VRd,s = (Asw/s) · z · fywd · cot θ
Exemple : VEd = 180 kN → HA8 espacés de 150 mm en zone critique
ELU Torsion
Vérification de la torsion (poutres de rive, balcons)
TEd ≤ TRd · Asw/s = TEd / (2·Ak·fywd·cot θ)
Exemple : TEd = 15 kN·m → cadres fermés HA8 espacés de 200 mm
ELU Ancrage des armatures
Vérification des longueurs d'ancrage et recouvrements
lbd = α·lb,rqd ≥ lb,min · l0 = α·lb,rqd
Exemple : HA20 en appui → lbd = 45 φ = 900 mm
ELU Zones nodales
Vérification des bielles comprimées aux appuis
σc = VEd / (b·a) ≤ fcd
Exemple : Appui sur poteau 30×30 cm → σc = 180×10³ / (300×300) = 2,0 MPa ≤ 14,17 MPa → OK
ELS Ouverture des fissures
Vérification de la largeur des fissures
wk = Sr,max · (εsm − εcm) ≤ wmax
Exemple : Parking couvert → wmax = 0,3 mm → OK
ELS Flèche instantanée
Vérification de la flèche sous charges de service
finst = (5·M·L²)/(48·E·I) ≤ L/250
Exemple : Poutre 8 m → finst = 18 mm ≤ 32 mm → OK
ELS Flèche différée
Prise en compte du fluage et du retrait
fdiff = finst · (1 + φ∞)
Exemple : φ∞ = 2,0 → fdiff = 18 × 3 = 54 mm → Vérifier L/250
📏 2. Poteaux
Vérifications complètes pour les poteaux soumis à la compression, à la flexion composée et au flambement. 📌 Exemple : Poteau 40×40 cm d'un immeuble R+5 — Béton C30/37
ELU Compression simple
Vérification de la résistance en compression centrée
NEd ≤ NRd = Ac·fcd + As·fyd
Exemple : NEd = 1600 kN → NRd = 2 628 kN → OK
ELU Compression excentrée
Vérification de l'interaction N-M (très fréquent)
Courbes d'interaction · MEd ≤ MRd(NEd)
Exemple : NEd = 1600 kN, MEd = 95 kN·m → 4 HA20 nécessaires
ELU Flambement
Vérification de l'élancement et des effets du second ordre
λ = L0/i · λ ≤ λlim · M2 = NEd·e2
Exemple : λ = 40 > λlim = 25 → effets du second ordre à prendre en compte
ELU Cisaillement
Vérification du cisaillement (zones sismiques)
VEd ≤ VRd
Exemple : VEd = 50 kN → cadres HA8 espacés de 150 mm
ELU Confinement
Dimensionnement des cadres pour le confinement du béton
ωwd ≥ 0,12 · (1 + λφ)
Exemple : DCM → cadres HA10 espacés de 100 mm en zones critiques
ELS Fissuration
Contrôle des fissures longitudinales
wk ≤ wmax
Exemple : wmax = 0,3 mm → OK avec enrobage 30 mm
ELS Déformations
Contrôle des déplacements horizontaux
dmax ≤ h/250
Exemple : dmax = 12 mm ≤ 3600/250 = 14,4 mm → OK
📊 3. Dalle à un sens
Vérifications pour les dalles portant dans une seule direction. 📌 Exemple : Dalle de logement portée de 4 m — Épaisseur 18 cm
ELU Flexion
Calcul des moments et armatures principales
MEd = p·L²/8 · As = MEd / (0,9·d·fyd)
Exemple : MEd = 15 kN·m/m → As = 230 mm²/m → HA10 tous les 30 cm
ELU Cisaillement
Vérification près des appuis
VEd = p·L/2 ≤ VRd,c
Exemple : VEd = 20 kN/m ≤ VRd,c = 35 kN/m → OK
ELU Poinçonnement
Si appui sur poteau (vérification locale)
vEd = VEd / (u1·d) ≤ vRd,c
Exemple : Poteau 30×30 cm → vEd = 0,45 MPa ≤ 0,41 MPa → armatures de poinçonnement
ELS Flèche
Vérification de la flèche sous charges de service
f = (5·p·L⁴)/(384·E·I) ≤ L/250
Exemple : f = 12 mm ≤ 4000/250 = 16 mm → OK
ELS Fissuration
Contrôle de l'ouverture des fissures
wk ≤ wmax
Exemple : Habitation → wmax = 0,3 mm → OK
📊 4. Dalle à deux sens
Vérifications pour les dalles portant dans deux directions. 📌 Exemple : Dalle 6×6 m — Épaisseur 20 cm
ELU Flexion (x et y)
Calcul des moments selon les deux directions
Mx = αx·p·Lx² · My = αy·p·Ly²
Exemple : α = 0,083 → Mx = My = 29,9 kN·m/m → HA10 tous les 15 cm
ELU Poinçonnement
Autour des poteaux
vEd = VEd / (u1·d) ≤ vRd,c
Exemple : VEd = 400 kN → vEd = 0,71 MPa > 0,41 MPa → armatures de poinçonnement
ELU Cisaillement
Aux appuis
VEd ≤ VRd,c
Exemple : VEd = 30 kN/m ≤ 45 kN/m → OK
ELS Flèches
Dans les deux directions
fx ≤ Lx/250 · fy ≤ Ly/250
Exemple : f = 8 mm ≤ 6000/250 = 24 mm → OK
ELS Fissuration
Deux nappes d'armatures
wk ≤ wmax
Exemple : wmax = 0,3 mm → OK avec enrobage 25 mm
🏗️ 5. Semelle isolée
Vérifications complètes pour les semelles sous poteaux. 📌 Exemple : Poteau 40×40 cm — Charge 900 kN — σadm = 0,25 MPa
ELU Portance du sol
Vérification de la pression sous la semelle
σ = N/A ≤ σadm · A = N/σadm
Exemple : A = 900/250 = 3,6 m² → semelle 1,9×1,9 m
ELU Flexion
Calcul des armatures dans les deux sens
MEd = σ·(B−b)²/8 · As = MEd / (0,9·d·fyd)
Exemple : MEd = 42 kN·m → As = 320 mm²/m → HA12 tous les 20 cm
ELU Poinçonnement
Autour du poteau
vEd = VEd / (u1·d) ≤ vRd,c
Exemple : vEd = 0,52 MPa ≤ 0,41 MPa → armatures de poinçonnement
ELU Cisaillement
Dans les deux directions
VEd ≤ VRd,c
Exemple : VEd = 150 kN ≤ 185 kN → OK
ELU Renversement
Si excentricité des charges
e = M/N ≤ B/6
Exemple : e = 0,15 m ≤ 1,9/6 = 0,32 m → OK
ELU Glissement
Sous efforts horizontaux
Fgl = (ΣV·tan φ) / HEd ≥ 1,5
Exemple : Fgl = 2,1 ≥ 1,5 → OK
ELS Tassement
Vérification du tassement absolu et différentiel
s ≤ sadm · Δs ≤ sdiff,adm
Exemple : s = 8 mm ≤ 25 mm → OK
🏗️ 6. Semelle filante
Vérifications pour les semelles continues sous murs ou rangées de poteaux.
ELU Pression sous semelle
Vérification de la portance
σ = (N + Gsemelle) / A ≤ σadm
ELU Flexion longitudinale
Armatures longitudinales
MEd = σ·B·L²/8
ELU Flexion transversale
Armatures transversales
MEd,t = σ·(B−b)²/8
ELU Cisaillement
VEd ≤ VRd,c
VEd = σ·(B−b)/2
ELU Poinçonnement
Aux poteaux éventuels
vEd ≤ vRd,c
ELS Tassement
Tassement absolu et différentiel
s ≤ sadm · Δs ≤ sdiff,adm

📝 Exemples concrets complets
Applications pratiques des vérifications sur des cas réels de bureau d'études.
🏗️ Exemple n°1 — Poutre d'un immeuble d'habitation
Données : Portée 6,00 m · Section 30×60 cm · G = 18 kN/m · Q = 12 kN/m
✅ Combinaison ELU ✅ Moment fléchissant ✅ Armatures longitudinales ✅ Effort tranchant ✅ Étriers ✅ Ancrages ✅ Fissuration ✅ Flèche instantanée ✅ Flèche différée
Résultat : Poutre dimensionnée avec 3 HA16 en travée, 3 HA14 sur appuis, cadres HA8 espacés de 150 mm en zone critique.
🏗️ Exemple n°2 — Poteau d'un bâtiment R+5
Données : Section 40×40 cm · Béton C30/37 · Acier B500B · NEd = 1 600 kN · MEd = 95 kN·m
✅ Compression ✅ Interaction N-M ✅ Flambement ✅ Armatures longitudinales ✅ Cadres ✅ Confinement ✅ Fissuration
Résultat : Poteau dimensionné avec 4 HA20 (1 256 mm²), cadres HA10 espacés de 100 mm en zones critiques.
🏗️ Exemple n°3 — Dalle pleine d'habitation
Données : Épaisseur 20 cm · Portée 5,00 m · G = 6,5 kN/m² · Q = 2,0 kN/m²
✅ Flexion ✅ Cisaillement ✅ Poinçonnement ✅ Flèche ✅ Fissuration ✅ Armatures de répartition
Résultat : Dalle armée avec HA10 espacés de 20 cm en sens principal, HA8 espacés de 30 cm en sens secondaire.
🏗️ Exemple n°4 — Semelle isolée
Données : Poteau 40×40 cm · Charge 900 kN · σadm = 0,25 MPa
✅ Surface minimale ✅ Pression du sol ✅ Excentricité ✅ Flexion ✅ Poinçonnement ✅ Cisaillement ✅ Ferraillage inférieur ✅ Enrobage ✅ Tassement
Résultat : Semelle 1,9×1,9 m armée avec HA12 espacés de 20 cm dans les deux sens.
