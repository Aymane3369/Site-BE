🧱 Fondamentaux du béton armé

Hypothèses de Bernoulli, états limites, classes de résistance, diagrammes contrainte-déformation, coefficients partiels, fluage, retrait, adhérence.
Formules fondamentales
fcd = αcc · fck / γc  →  fcd : résistance de calcul du béton
fyd = fyk / γs  →  fyd : limite d'élasticité de calcul de l'acier
fcm = fck + 8  →  résistance moyenne à la compression
Ecm = 22 000 · (fcm/10)0,3  →  module d'élasticité secant
εcu = 0,0035  →  déformation ultime du béton en compression
εyd = fyd / Es  →  déformation à la limite élastique de l'acier
Domaine : Tous les éléments en BA γc = 1,5 γs = 1,15 αcc = 0,85 (poutres) ou 1,0 (poteaux)
Exemple : Béton C25/30, acier S500B
fcd = 0,85 × 25 / 1,5 = 14,17 MPa
fyd = 500 / 1,15 = 434,78 MPa
fcm = 25 + 8 = 33 MPa
Ecm = 22000 × (33/10)0,3 = 31 000 MPa
Exercice 1.1 : Calculer fcd, fyd, Ecm pour un béton C30/37 et un acier S500B.
Corrigé :
fcd = 0,85 × 30 / 1,5 = 17,0 MPa
fyd = 500 / 1,15 = 434,8 MPa
fcm = 30 + 8 = 38 MPa
Ecm = 22000 × (38/10)0,3 = 32 800 MPa
Tome 2

📐 Flexion simple des poutres

Calcul du moment de calcul, position de la fibre neutre, bras de levier, section simplement armée, section doublement armée, armatures minimales et maximales.
Formules de flexion simple
MEd ≤ MRd  →  vérification de la résistance en flexion
μ = MEd / (b · d² · fcd)  →  moment réduit
α = 1,25 · (1 − √(1 − 2μ))  →  bras de levier réduit
z = d · (1 − 0,4·α)  →  bras de levier réel
As = MEd / (z · fyd)  →  section d'armatures tendues
As,min = 0,26 · (fctm / fyk) · b · d  →  armature minimale
As,max = 0,04 · Ac  →  armature maximale (4% de la section de béton)
Domaine : Poutres, dalles unidirectionnelles d ≈ 0,9·h μ < 0,372 (section simplement armée) Si μ > 0,372 → section doublement armée
Exemple : Poutre 20×50 cm, MEd = 80 kN·m, béton C25/30, acier S500B
d = 0,9 × 50 = 45 cm
μ = 80×10⁶ / (200×450²×14,17) = 0,139
α = 1,25 × (1 − √(1 − 2×0,139)) = 0,187
z = 450 × (1 − 0,4×0,187) = 416 mm
As = 80×10⁶ / (416×434,8) = 442 mm² → soit 3 HA14 (462 mm²)
Exercice 2.1 : Dimensionner une poutre 25×55 cm soumise à MEd = 150 kN·m. Béton C30/37, acier S500B.
Corrigé :
d = 0,9 × 55 = 49,5 cm
fcd = 0,85×30/1,5 = 17,0 MPa
μ = 150×10⁶ / (250×495²×17,0) = 0,144
α = 1,25×(1−√(1−2×0,144)) = 0,194
z = 495×(1−0,4×0,194) = 457 mm
As = 150×10⁶ / (457×434,8) = 754 mm² → 3 HA20 (942 mm²)
Tome 3

✂️ Effort tranchant

Bielles et tirants, résistance du béton, cadres, inclinaison des bielles, espacement maximal des cadres.
Formules de l'effort tranchant
VEd ≤ VRd  →  vérification du cisaillement
VRd,c = [0,12 · k · (100·ρl·fck)1/3] · bw · d  →  résistance sans armatures transversales
k = 1 + √(200/d) ≤ 2,0
ρl = Asl / (bw · d) ≤ 0,02
VRd,s = (Asw / s) · z · fywd · cot θ  →  résistance avec armatures transversales
VRd,max = (bw · z · ν1 · fcd) / (cot θ + tan θ)  →  résistance des bielles de béton
Smax = 0,75 · d · (1 + cot α)  →  espacement maximal des cadres
Domaine : Poutres, dalles, voiles θ = 45° (par défaut) cot θ = 1,0 à 2,5 ν1 = 0,6 · (1 − fck/250)
Exemple : Poutre 20×50 cm, VEd = 120 kN, béton C25/30, acier S500B, cadres HA8 (Asw = 100 mm²)
d = 450 mm, bw = 200 mm
VRd,s = (100/s) × 416 × 434,8 × 1,0
Pour VRd,s ≥ 120 kN → s ≤ 150 mm
Exercice 3.1 : Vérifier le cisaillement d'une poutre 25×60 cm soumise à VEd = 180 kN. Béton C30/37, cadres HA10 (Asw = 157 mm²), s = 120 mm.
Corrigé :
d = 0,9×60 = 54 cm, z = 0,9×540 = 486 mm
fyd = 434,8 MPa, fcd = 17,0 MPa
VRd,s = (157/120) × 486 × 434,8 × 1,0 = 276 kN
VEd = 180 kN ≤ 276 kN → ✅ OK
VRd,max = (250×486×0,6×(1−30/250)×17,0)/2 = 545 kN → OK
Tome 4

🔄 Torsion

Torsion simple, torsion + flexion, armatures longitudinales, armatures transversales.
Formules de torsion
TEd ≤ TRd  →  vérification de la torsion
TRd,max = 2 · Ak · teff · fcd · sin θ · cos θ  →  résistance des bielles comprimées
Asw / s = TEd / (2 · Ak · fywd · cot θ)  →  armatures transversales
Asl,tor = TEd · uk / (2 · Ak · fyd)  →  armatures longitudinales
Ak = aire intérieure du contour (bw − teff) × (h − teff)
uk = périmètre intérieur du contour
Domaine : Poutres, poutres courbes, consoles teff = A / u (épaisseur de la paroi équivalente) θ = 45° (par défaut)
Exemple : Poutre 30×60 cm, TEd = 20 kN·m, béton C25/30
teff = 2×A/u = 2×(300×600)/(2×(300+600)) = 80 mm
Ak = (300−80)×(600−80) = 114 400 mm²
uk = 2×(220+520) = 1 480 mm
Asw/s = 20×10⁶ / (2×114400×434,8×1) = 0,201 mm → HA8 avec s ≤ 250 mm
Exercice 4.1 : Dimensionner les armatures de torsion pour une poutre 25×55 cm soumise à TEd = 15 kN·m. Béton C30/37.
Corrigé :
teff = 2×250×550 / 1600 = 172 mm
Ak = (250−172)×(550−172) = 30 084 mm²
uk = 2×(78+378) = 912 mm
Asw/s = 15×10⁶ / (2×30084×434,8×1) = 0,574 mm²/mm → HA8 (50 mm²) espacés de 87 mm
Tome 5

📌 Poinçonnement

Dalles, semelles, têtes de poteaux. Vérification du poinçonnement et armatures de poinçonnement.
Formules de poinçonnement
VEd ≤ VRd,c  →  vérification sans armatures de poinçonnement
vEd = VEd / (u1 · d)  →  contrainte de poinçonnement
u1 = 2·π·(c1 + c2)/2 + 2·π·2·d  →  périmètre critique
vRd,c = 0,12 · k · (100·ρl·fck)1/3  →  résistance au poinçonnement sans armatures
vRd,max = 0,5 · ν · fcd  →  résistance maximale des bielles
Asw = (vEd − vRd,c) · u1 · d / (fywd · sin α)  →  armatures de poinçonnement
Domaine : Dalles, semelles isolées u1 : périmètre à 2·d du contour du poteau ν = 0,6 · (1 − fck/250)
Exemple : Dalle 20 cm, poteau 30×30 cm, VEd = 400 kN, béton C25/30
d = 170 mm, u1 = 4×300 + 2×π×2×170 = 3 336 mm
vEd = 400×10³ / (3336×170) = 0,71 MPa
vRd,c = 0,12×1,95×(100×0,01×25)1/3 = 0,41 MPa
vEd > vRd,c → armatures de poinçonnement nécessaires
Exercice 5.1 : Vérifier le poinçonnement d'une dalle 25 cm sous un poteau 40×40 cm avec VEd = 600 kN. Béton C30/37.
Corrigé :
d = 0,9×250 = 225 mm
u1 = 4×400 + 2×π×2×225 = 4 427 mm
vEd = 600×10³ / (4427×225) = 0,60 MPa
vRd,c = 0,12×1,82×(100×0,01×30)1/3 = 0,44 MPa
vEd > vRd,c → armatures de poinçonnement nécessaires
Tome 6

📏 Compression — Poteaux

Compression centrée, compression excentrée, interaction N-M, flambement, effets du second ordre.
Formules de compression
NRd = Ac · fcd + As · fyd  →  résistance en compression centrée
λ = L0 / i  →  élancement du poteau
i = √(I/A)  →  rayon de giration
λlim = 20 · A · B · C / √n  →  élancement limite
M2 = NEd · e2  →  moment du second ordre
e2 = (1/r) · L0² / c  →  excentricité du second ordre
1/r = Kr · Kφ · 1/r0  →  courbure
Domaine : Poteaux, piliers L0 = k·L (longueur de flambement) λlim ≈ 25 à 35 (selon les conditions)
Exemple : Poteau 30×30 cm, hauteur 3,5 m, NEd = 1200 kN, béton C25/30, 4 HA16
Ac = 300×300 = 90 000 mm², As = 4×201 = 804 mm²
NRd = 90 000×14,17 + 804×434,8 = 1 275 + 349 = 1 624 kN
λ = L0/i = 3500/(0,289×300) = 40
λlim ≈ 25 → effets du second ordre à prendre en compte
Exercice 6.1 : Vérifier un poteau 35×35 cm, hauteur 4,0 m, NEd = 1800 kN. Béton C30/37, 4 HA20.
Corrigé :
Ac = 350×350 = 122 500 mm², As = 4×314 = 1 256 mm²
NRd = 122500×17,0 + 1256×434,8 = 2 082 + 546 = 2 628 kN
λ = 4000/(0,289×350) = 39,5
NEd = 1800 kN ≤ 2628 kN → ✅ OK
λ < λlim → effets du second ordre négligeables
Tome 7

📊 Dalles

Dalles unidirectionnelles, bidirectionnelles, pleines, nervurées, champignon. Calcul des moments, flèches, fissuration, ferraillage.
Formules pour dalles
MEd = α · p · Lx²  →  moment dans une dalle (α selon les conditions d'appui)
Flèche = (5 · p · L⁴) / (384 · E · I)  →  flèche d'une dalle simplement appuyée
As = MEd / (0,9 · d · fyd)  →  armatures de dalle
ρ = As / (b · d) ≤ 0,02  →  taux d'armatures
h ≥ L / 25  →  hauteur minimale pour les dalles (non vérifiée)
Domaine : Planchers, dalles de bâtiment α = 0,083 (dalle appuyée sur 4 côtés, Ly/Lx=1) α = 0,125 (dalle simplement appuyée)
Exemple : Dalle 6×6 m, p = 10 kN/m², épaisseur 20 cm
MEd = 0,083 × 10 × 6² = 29,9 kN·m/m
d = 0,9×200 = 180 mm
As = 29,9×10⁶ / (0,9×180×434,8) = 425 mm²/m → HA10 tous les 15 cm
Exercice 7.1 : Dimensionner une dalle 5×5 m, p = 12 kN/m², épaisseur 18 cm. Béton C25/30, acier S500B.
Corrigé :
MEd = 0,083 × 12 × 5² = 24,9 kN·m/m
d = 0,9×180 = 162 mm
As = 24,9×10⁶ / (0,9×162×434,8) = 392 mm²/m → HA10 (78,5 mm²) espacés de 200 mm
Tome 8

🪜 Escaliers

Escaliers droits, balancés, paillasses, paliers. Calcul des charges, moments, armatures.
Formules pour escaliers
Gpaillasse = h · γBA / cos α + Grevêtement  →  charge permanente d'une paillasse
Qpaillasse = Qexploitation / cos α  →  charge d'exploitation d'une paillasse
MEd = (γG·G + γQ·Q) · L² / 8  →  moment de calcul
As = MEd / (0,9·d·fyd)  →  armatures de la paillasse
H = n · hmarche  →  hauteur totale
L = (n−1) · gmarche  →  longueur horizontale
Domaine : Escaliers intérieurs et extérieurs α = pente de l'escalier (tan α = H/L) hmarche ≈ 17 cm, gmarche ≈ 28 cm
Exemple : Escalier droit, hauteur 3,0 m, 18 marches, paillasse 15 cm
H = 18×0,17 = 3,06 m, L = 17×0,28 = 4,76 m
α = atan(3,06/4,76) = 32,7°, cos α = 0,841
G = 0,15×25/0,841 + 1,0 = 5,46 kN/m²
Q = 2,5/0,841 = 2,97 kN/m²
MEd = (1,35×5,46 + 1,5×2,97) × 4,76²/8 = 30,2 kN·m/m
Tome 9

🏗️ Fondations

Semelles isolées, semelles filantes, radiers. Vérification du sol, flexion, cisaillement, poinçonnement.
Formules pour fondations
σsol = NEd / A + MEd / (I/v)  →  pression sous semelle
σsol,max ≤ σadm  →  vérification de la portance
e = MEd / NEd ≤ B/6  →  excentricité
MEd,semelle = σsol · (B−b)2 / 8  →  moment dans la semelle
As = MEd / (0,9·d·fyd)  →  armatures de la semelle
VEd = σsol · (B−b)/2  →  effort tranchant
Domaine : Semelles sous poteaux, murs σadm : contrainte admissible du sol B ≥ √(N/σadm) (semelle carrée)
Exemple : Semelle isolée sous poteau 30×30 cm, NEd = 600 kN, σadm = 0,25 MPa
A = 600 / 250 = 2,4 m² → B = 1,55 m (semelle 1,6×1,6 m)
MEd = 250 × (1,6−0,3)²/8 = 52,8 kN·m/m
d = 0,9×h (h ≈ 40 cm) → d = 360 mm
As = 52,8×10⁶ / (0,9×360×434,8) = 375 mm²/m → HA12 espacés de 200 mm
Tome 10

🧱 Voiles

Efforts verticaux, efforts horizontaux, ferraillage, ouvertures.
Formules pour voiles
NRd = Ac · fcd + As · fyd  →  résistance en compression
VRd = (Asw / s) · z · fywd · cot θ  →  résistance au cisaillement
MEd = HEd · L/2  →  moment dû aux efforts horizontaux
As,min = 0,002 · Ac  →  armature minimale verticale
As,min,h = 0,001 · Ac  →  armature minimale horizontale
Domaine : Murs porteurs, noyaux de bâtiment Épaisseur minimale : 15 cm (voile de contreventement)
Tome 11

🔩 Consoles

Consoles courtes, consoles longues, méthode des bielles et tirants.
Formules pour consoles
MEd = FEd · a  →  moment de calcul
VEd = FEd  →  effort tranchant
Ft = MEd / z + FEd · a1 / z  →  effort dans le tirant
As = Ft / fyd  →  armatures principales
ac ≥ a/2  →  condition de console courte
VRd,max = 0,5 · b · d · ν · fcd  →  résistance des bielles
Domaine : Consoles de poutres, appuis a : distance de la force à l'appui Console courte : a/d ≤ 0,5
Tome 12

🏔️ Murs de soutènement

Poussée des terres, glissement, renversement, portance, ferraillage.
Formules pour murs de soutènement
Pa = 0,5 · Ka · γ · h²  →  poussée des terres (Coulomb)
Ka = tan²(π/4 − φ/2)  →  coefficient de poussée active
Fglissement = (ΣV · tan φ) / Pa ≥ 1,5  →  vérification du glissement
Frenversement = ΣMstabilisateur / Mrenversant ≥ 2,0  →  vérification du renversement
MEd = Pa · h/3  →  moment à la base du mur
As = MEd / (0,9·d·fyd)  →  armatures du voile
Domaine : Murs de soutènement, quais φ : angle de frottement interne du sol γ : poids volumique du sol
Tome 13

🔍 Vérifications ELS

Ouverture des fissures, flèches, vibrations, déformations différées.
Formules ELS
wk = Sr,max · (εsm − εcm)  →  largeur de fissure
Sr,max = 3,4 · c + 0,425 · k1 · k2 · φ / ρp,eff  →  espacement maximal des fissures
Flèche instantanée = (5 · M · L²) / (48 · E · I)  →  flèche (poutre appuyée)
Flèche différée = Flèche instantanée · (1 + φ∞)  →  flèche à long terme
wk,max = 0,3 mm (environnement XC) ou 0,2 mm (environnement XD/XS)
Domaine : Toutes les structures φ∞ : coefficient de fluage (≈ 2,0 à 3,0) ρp,eff : taux d'armatures effectif
Tome 14

🛡️ Durabilité

Classes d'exposition XC, XD, XS, XF, XA, enrobage minimal, durée de vie, carbonatation, corrosion.
Formules de durabilité
cmin = cnom − Δcdev  →  enrobage minimal
cnom = cmin,dur + Δcdev  →  enrobage nominal
xc = k · √t  →  profondeur de carbonatation
Dcl = coefficient de diffusion des chlorures (m²/s)
Durée de vie = tinitiation + tpropagation (modèle de Tuutti)
Domaine : Tous les ouvrages en BA XC1 à XC4 : carbonatation XD1 à XD3 : chlorures (hors marin) XS1 à XS3 : milieu marin
Exemple : Classe XC3 (alternance humide/sec), durée de vie 50 ans
cmin,dur = 20 mm, cnom = 20 + 10 = 30 mm
Profondeur de carbonatation à 50 ans : k = 2 mm/√an → xc = 2×√50 = 14 mm → OK
Tome 15

🔧 Détails d'armatures

Longueurs d'ancrage, recouvrements, crochets, rayons de cintrage, espacement des barres, dispositions constructives.
Formules de détails
lbd = α1 · α2 · α3 · α4 · α5 · lb,rqd ≥ lb,min  →  longueur d'ancrage de calcul
lb,rqd = (φ · σsd) / (4 · fbd)  →  longueur d'ancrage de base
fbd = 2,25 · η1 · η2 · fctd  →  contrainte d'adhérence
l0 = α1 · α2 · α3 · α4 · α5 · lb,rqd ≥ l0,min  →  longueur de recouvrement
Rayon de cintrage = ≥ 4φ (pour φ ≤ 16 mm) ou ≥ 7φ (pour φ > 16 mm)
Domaine : Tous les éléments en BA lbd ≈ 30 à 60 φ (selon le diamètre et la qualité du béton) Recouvrement ≈ 40 à 80 φ
Tome 16

📋 Applications complètes

Descente de charges, détermination des efforts (N, V, M, T), calcul manuel selon l'Eurocode 2, vérification ELU et ELS, ferraillage détaillé, plans de ferraillage, contrôle dans Robot Structural Analysis / Arche.
Méthodologie complète
1. Descente de charges : Gk + Qk → efforts aux éléments porteurs
2. Détermination des efforts : NEd, VEd, MEd, TEd
3. Calcul manuel EC2 : flexion, cisaillement, torsion, poinçonnement, compression
4. Vérification ELU : NRd ≥ NEd, MRd ≥ MEd, VRd ≥ VEd
5. Vérification ELS : contraintes, fissuration, flèches
6. Ferraillage : armatures longitudinales, transversales, étriers
7. Plans de ferraillage : coupes, nomenclatures
8. Contrôle logiciel : Robot Structural Analysis, Arche
Domaine : Tous les bâtiments et ouvrages Vérification complète selon EN 1992-1-1 Applications : bâtiments, ponts, ouvrages d'art
Exemple complet : Poutre 25×55 cm, portée 6 m, charges G=8 kN/m, Q=6 kN/m, béton C25/30, acier S500B
1. ELU : P=1,35×8+1,5×6=19,8 kN/m → M=19,8×6²/8=89,1 kN·m
2. As : d=495 mm → As=89,1×10⁶/(0,9×495×434,8)=459 mm² → 3 HA14
3. ELS : σb=4,2 MPa ≤ 0,45×14,17=6,38 MPa → OK
4. Cisaillement : V=59,4 kN → τ=59,4×10³/(250×495)=0,48 MPa ≤ 0,15×25/1,15=3,26 MPa → OK
5. Étriers : HA6 espacés de 200 mm (zones courantes), 150 mm (zones critiques)
6. Vérification Robot : Confirmation des résultats avec une marge < 5%
